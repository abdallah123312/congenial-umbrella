# منصة الأبطال — دليل التشغيل والنشر

المشروع ده نسخة حقيقية (مش داخل Claude) من منصتك، جاهزة تتحول لموقع بعدين "تطبيق يتحط على الشاشة". اتبع الخطوات بالترتيب.

## 1. جهّز قاعدة بيانات مجانية (Firebase) — 5 دقايق

1. روح على https://console.firebase.google.com وسجل دخول بحساب جوجل.
2. اضغط **إنشاء مشروع (Add project)** واديله أي اسم (مثلاً alabtal).
3. من القائمة الجانبية: **Build → Realtime Database → Create Database**.
4. اختار أي منطقة، وبعدين اختار **Start in test mode** (يسمح بالقراءة والكتابة من غير تسجيل دخول — مناسب للبداية).
5. هتلاقي فوق رابط شبيه بده:
   `https://alabtal-xxxxx-default-rtdb.firebaseio.com`
   انسخه.

## 2. ظبط المشروع

1. افتح ملف `src/storage.js`.
2. غيّر السطر ده بالرابط اللي نسخته:
   ```js
   const DB_URL = "https://alabtal-xxxxx-default-rtdb.firebaseio.com";
   ```

## 3. شغّل المشروع على جهازك (اختياري، للتجربة)

محتاج تثبت Node.js من https://nodejs.org (لو مش مثبت).

```bash
npm install
npm run dev
```

هيديك رابط زي `http://localhost:5173` افتحه في المتصفح.
- الصفحة العادية = شاشة الطلاب.
- ضيف `?teacher=1` في الآخر (يعني `http://localhost:5173/?teacher=1`) = لوحة تحكمك.

## 4. انشر الموقع مجانًا (Vercel)

1. روح على https://vercel.com وسجل دخول (تقدر بحساب جيميل مباشرة).
2. اضغط **Add New → Project**.
3. اختار **Deploy without Git** أو اربط GitHub لو عندك مستودع — الأسهل: اسحب مجلد المشروع كامل في صفحة الرفع.
4. Vercel هيبني المشروع تلقائي ويديك رابط زي:
   `https://alabtal.vercel.app`

كده المنصة بقت شغالة على الإنترنت فعليًا، أي حد يقدر يفتحها.

- رابط الطلاب: `https://alabtal.vercel.app`
- رابط لوحتك: `https://alabtal.vercel.app/?teacher=1` (خليه سري وميتشاركش)

## 5. خليه "يتحط" زي تطبيق على الموبايل (PWA)

المشروع فيه ملف `manifest.json` و `sw.js` جاهزين لده تلقائيًا. اللي محتاجه بس:

**على أندرويد (Chrome):** افتح الرابط → هتظهر رسالة "إضافة إلى الشاشة الرئيسية" تلقائي، أو من قائمة المتصفح (⋮) اختار **تثبيت التطبيق**.

**على آيفون (Safari):** افتح الرابط → دوس على زرار المشاركة (Share) → **إضافة إلى الشاشة الرئيسية**.

هيظهر أيقونة زي أي تطبيق عادي، ويفتح بدون شريط المتصفح.

> ملحوظة: غيّر الأيقونتين `public/icon-192.png` و `public/icon-512.png` بشعارك الحقيقي وقت ما يكون جاهز.

## 6. لو حبيت تنزله على App Store / Google Play فعلاً لاحقًا

ده اختياري ومرحلة تانية، محتاج:
- حساب مطور جوجل (25$ مرة واحدة) أو آبل (99$/سنة).
- أداة زي **Capacitor** بتلف نفس الكود ده في تطبيق حقيقي (APK / iOS build).
- مراجعة المتجر نفسه (ممكن تاخد أيام).

لو وصلت للمرحلة دي وحابب مساعدة، قولّي وقتها هنظبطها خطوة بخطوة.

## 7. تسجيل الطلاب (اسم + رقم + كلمة سر)

المنصة دلوقتي بتطلب من كل طالب إنه يعمل حساب (اسم + رقم موبايل + كلمة سر) قبل ما يقدر يشوف المواد. كل الحسابات دي بتظهر عندك في لوحة التحكم تحت تبويب **"الطلاب"** — تقدر تشوف اسم ورقم كل طالب سجل، وتمسح أي حساب لو حبيت.

**بالنسبة للكسب من المنصة:** التسجيل مش بوابة دفع، ده بس بيوريك مين الطلاب. الطريقة العملية دلوقتي:
1. الطالب يعمل حساب على المنصة.
2. يبعتلك يدفع (فودافون كاش / انستاباي / أي وسيلة تحب).
3. تدخل لوحة التحكم، تضيف كود فتح للمحاضرة، وتبعتهولّه شخصيًا.

لو حبيت لاحقًا تدمج بوابة دفع حقيقية (زي Paymob أو فوري) عشان الطالب يدفع ويتفتحله الكود أوتوماتيك من غير ما تتدخل، ده ممكن بس محتاج خطوة تانية — قولّي وقتها.

> **ملحوظة أمان:** كلمات السر بتتخزن مشفرة (مش نص صريح)، لكن قاعدة البيانات لسه في "test mode" (مفتوحة لأي حد يعرف الرابط). لو المنصة بدأت تاخد استخدام حقيقي وفلوس، الأنسب نظبط قواعد Firebase أقوى — قولّي وقتها نعملها.

## 8. الميزات الجديدة (شعارات، اختبارات، تقدم، دعم)

- **شعار لكل مادة:** لما تضيف مادة جديدة، فيه خانة صغيرة تقدر تحط فيها إيموجي (زي 📐 أو 🧪) يبقى شعارها.
- **اختبارات بعد كل محاضرة:** من جوه لوحة التحكم، افتح المادة، وجنب أي محاضرة دوس على "الاختبار" وضيف أسئلة اختيار من متعدد. الطالب هيقدر يبدأ الاختبار بعد ما يفتح المحاضرة.
- **متابعة تقدم الطالب:** الطالب يقدر يعلّم أي محاضرة بـ"خلصتها"، وده بيظهره كـ progress bar فوق عنده.
- **شاشة ترحيبية:** أول ما الطالب يفتح الرابط بيشوف شاشة تعريفية بالمنصة قبل التسجيل.
- **دعم واتساب وفيسبوك:** ظاهرين في الشاشة الترحيبية وشاشة التسجيل، وكمان زرار عائم للدعم وفوتر فيه لينك الصفحة في كل شاشات الطالب.

كل الميزات دي بتتحدث تلقائي بمجرد رفع النسخة الجديدة (نفس خطوات الرفع اللي عملناها قبل كده).

## 9. الفيديو بشاشة كاملة والواجبات

- **شاشة كبيرة للفيديو:** لما الطالب يدوس "شغّل"، الفيديو دلوقتي بيفتح على الشاشة كلها (مش صندوق صغير في النص).
- **رفع صور الواجب:** من لوحة التحكم، جنب أي محاضرة دوس على "الواجب"، واختار صورة من موبايلك (زي صورة ورقة تمارين). الطالب هيشوفها كـ"شوف الواجب" جنب المحاضرة بعد ما يفتحها.
- **إحصائيات الاختبارات:** تبويب "الإحصائيات" في لوحة التحكم بيوريك مين امتحن، في أنهي محاضرة، وبكام.

## 10. الصفوف الدراسية (من الرابع الابتدائي للثالث الثانوي)

- لما تضيف مادة جديدة من لوحة التحكم، هتختار كمان **الصف الدراسي** اللي المادة دي ليه (من الرابع الابتدائي لحد الثالث الثانوي).
- الطالب وهو بيسجل حساب، بيختار هو في أنهي صف.
- بعد التسجيل، الطالب هيشوف بس المواد اللي على نفس صفه — مش هيشوف مواد الصفوف التانية خالص.
- في تبويب "الطلاب" بلوحة التحكم، هتلاقي صف كل طالب مكتوب جنب رقمه.

## 11. تطبيق أندرويد حقيقي (APK) بدل الموقع

المشروع دلوقتي فيه كل حاجة جاهزة لبناء تطبيق أندرويد حقيقي بأداة اسمها **Capacitor** — بتاخد نفس الكود وتحوله لتطبيق ملموس (ملف .apk) تقدر تثبته على أي موبايل أندرويد من غير متجر أصلاً، أو ترفعه على Google Play بعدين لو حبيت.

### المتطلبات
- **جهاز كمبيوتر** (ويندوز أو ماك) — البناء نفسه مينفعش من الموبايل.
- تثبيت **Node.js** من https://nodejs.org (لو مش مثبت).
- تثبيت **Android Studio** من https://developer.android.com/studio (مجاني، حجمه كبير شوية فخد وقتك في التحميل).

### الخطوات
1. افتح الكمبيوتر، فك ضغط مجلد المشروع، وافتح فيه Terminal / Command Prompt.
2. ثبّت كل المكتبات المطلوبة:
   ```bash
   npm install
   ```
3. اظبط رابط قاعدة البيانات في `src/storage.js` (لو لسه مش مظبوط).
4. ابني نسخة الإنتاج من الموقع:
   ```bash
   npm run build
   ```
5. جهّز مجلد أندرويد لأول مرة بس (مرة واحدة طول العمر):
   ```bash
   npx cap add android
   ```
6. مزامنة الكود مع مشروع أندرويد وفتحه في Android Studio:
   ```bash
   npm run android
   ```
7. Android Studio هيفتح تلقائي. سيبه يخلص التحميل الأول (ممكن ياخد شوية وقت أول مرة).
8. من فوق في Android Studio: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
9. لما يخلص، هيديك إشعار فيه لينك **locate** — دوس عليه يوديك لمكان ملف الـ APK.
10. ابعت ملف الـ APK ده لنفسك (واتساب لنفسك، أو رفعه Google Drive)، افتحه من الموبايل، ودوس تثبيت (هيطلب إذن "تثبيت من مصادر غير معروفة" — وافق عليه).

كده عندك تطبيق حقيقي مثبت على الموبايل، بأيقونة ودخول مباشر، من غير متصفح خالص.

### لو حبيت ترفعه على Google Play بعدين
نفس ملف الـ APK ده (أو نسخة موقعة منه) تقدر ترفعها على حساب مطور Google Play (25$ مرة واحدة) من https://play.google.com/console — الخطوات موجودة هناك خطوة بخطوة، وأقدر أساعدك فيها لو وصلت للمرحلة دي.

### مفيش كمبيوتر خالص؟
فيه خدمات أونلاين زي **Appflow** (من نفس شركة Capacitor) أو **PWABuilder** (https://pwabuilder.com) بتاخد رابط موقعك المنشور وتبنيلك APK أونلاين من غير Android Studio خالص. أبسط حل: افتح https://pwabuilder.com من موبايلك، حط رابط موقعك (`https://alabtal-project-2.vercel.app`)، ودوس على خيار Android — هيديك ملف تقدر تنزله وتثبته مباشرة.

## 12. الإشعارات (توصل للموبايل حتى لو التطبيق مقفول)

بنستخدم خدمة مجانية اسمها **OneSignal**، سهلة جدًا وملهاش أي تكلفة على عدد الطلاب ده.

### الإعداد (5 دقايق)
1. روح على https://onesignal.com واعمل حساب مجاني (بجيميل أسهل).
2. دوس **New App/Website**، اديله اسم زي "الأبطال".
3. اختار **Web Push** كنوع المنصة.
4. حط رابط موقعك (زي `https://alabtal-project-2.vercel.app`) في خانة **Site URL**.
5. بعد ما يخلص الإعداد، روح لـ **Settings → Keys & IDs** وهتلاقي:
   - **OneSignal App ID**
   - **REST API Key**

### ظبط المشروع
1. افتح `index.html` وحط الـ App ID بدل `ONESIGNAL_APP_ID_HERE`.
2. افتح `src/onesignal.js` وحط الـ App ID والـ REST API Key بدل القيم اللي مكتوبة `YOUR-...`.

### الاستخدام
- الطالب يدوس على أيقونة الجرس 🔔 اللي فوق في المنصة عشان يوافق على استقبال الإشعارات (المتصفح هيسأله إذن).
- أي مرة تضيف محاضرة جديدة من لوحة التحكم، هيتبعت إشعار تلقائي لكل الطلاب اللي فعّلوا الإشعارات.

> **ملحوظة أمان:** الـ REST API Key بيبقى ظاهر في كود الموقع (زي كل حاجة تانية في المشروع ده). ده معناه إن أي حد فاهم في التقنية يقدر يستخدمه يبعت إشعارات كمان. للاستخدام الشخصي الحالي ده مقبول، بس لو المنصة كبرت جدًا قولّي نأمنها بطريقة أقوى (سيرفر بسيط بينك وبين OneSignal).

## 13. تأمين المنصة (تسجيل دخول حقيقي بدل الكود المفتوح)

⚠️ **مهم جدًا قبل ما تبدأ:** التغيير ده بيبدّل نظام الدخول بالكامل. **أي طالب سجل قبل كده هيحتاج يعمل حساب جديد تاني** — الحسابات القديمة مش هتشتغل مع النظام الجديد. لو عندك طلاب مسجلين فعلاً، قولهم يسجلوا تاني بعد ما تخلص الخطوات دي.

### 1. فعّل تسجيل الدخول في Firebase
1. من https://console.firebase.google.com افتح مشروعك.
2. من القائمة الجانبية: **Build → Authentication → Get started**.
3. من تبويب **Sign-in method**، فعّل **Email/Password**.

### 2. سجّل "تطبيق ويب" عشان تاخد الإعدادات الكاملة
1. من صفحة المشروع الرئيسية (الصفحة اللي فيها Overview)، دوس على أيقونة **</>** (Web) لإضافة تطبيق ويب.
2. اديله أي اسم (زي "alabtal-web") ودوس **Register app**.
3. هيديك كائن (object) فيه `apiKey` و `authDomain` و `projectId` وغيرهم — انسخهم.

### 3. ظبط الكود
افتح `src/firebase.js` واستبدل القيم دي بالقيم اللي نسختها:
```js
const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  databaseURL: "...",  // نفس رابط قاعدة البيانات القديم
  projectId: "...",
};
```

### 4. ارفع النسخة الجديدة
نفس خطوات الرفع المعتادة (npm install لو بتشتغل محليًا، أو Vercel Drop للنسخة المرفوعة).

### 5. سجّل حسابك كمعلم
1. افتح رابط لوحة التحكم بتاعتك (`?teacher=1`).
2. اختار تبويب **"حساب جديد"**، اكتب إيميلك الحقيقي وكلمة سر (6 حروف على الأقل)، ودوس **إنشاء الحساب**.

### 6. خد الـ UID بتاعك وقفل القاعدة
1. من Firebase Console: **Build → Authentication → Users**، هتلاقي حسابك في الجدول ونسخ عمود **User UID**.
2. افتح ملف `firebase-rules.json` في المشروع، واستبدل كل حرف `ADMIN_UID_HERE` (فيه 4 أماكن) بالـ UID اللي نسخته.
3. من Firebase Console: **Build → Realtime Database → Rules**، امسح اللي موجود، والصق محتوى `firebase-rules.json` بعد التعديل، ودوس **Publish**.

كده خلاص القاعدة قفلت. محدش يقدر يشوف أو يعدل بيانات الطلاب أو المحتوى غيرك، وكل طالب بيشوف بياناته هو بس.

> **حدود مهمة تعرفها:** الإعداد ده بيمنع أي حد برا التطبيق من قراءة أو تعديل بيانات الطلاب مباشرة، وده أهم حاجة. لكنه **مش بيخبي أكواد فتح المحاضرات عن طالب مسجل داخل** لو دور تقنيًا في المتصفح (Developer Tools) — لأن التطبيق نفسه بيحمّل كل الأكواد عشان يقارنها. إخفاء الأكواد بالكامل محتاج سيرفر حقيقي يتحقق منها بدل المتصفح، وده تعقيد إضافي لو حبيت نوصله لاحقًا.
